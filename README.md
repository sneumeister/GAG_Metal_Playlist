# GAG Metal Playlist

Zuordnung von Folgen des Podcasts [Geschichten aus der Geschichte](https://www.geschichte.fm/) (GAG) zu historisch passenden Rock-/Metal-Songs.

Ziel ist eine Trefferliste: **Folge ↔ Song ↔ Begründung ↔ Spotify/YouTube-Link** — nur bei engen Bezügen (Person, Schlacht, Ereignis, Ort oder konkrete Sage/Figur im historischen Kontext), keine losen Themen-Parallelen.

## Aktuelle Liste

- [Markdown](GAG_Metal_playlist.md)
- [HTML (sortierbar)](GAG_Metal_playlist.html) · [Live-Ansicht (GitHub Pages)](https://sneumeister.github.io/GAG_Metal_Playlist/)

Die Live-Ansicht läuft über GitHub Pages und rendert die HTML-Datei im Browser.

Folgendaten wurden diesem Repo entnommen: [ideadapt/geschichten-aus-der-geschichte-data](https://github.com/ideadapt/geschichten-aus-der-geschichte-data) (`data/episodes.jsonl`).
