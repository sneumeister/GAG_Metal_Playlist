# GAG Metal Playlist

Zuordnung von Folgen des Podcasts [Geschichten aus der Geschichte](https://www.geschichte.fm/) (GAG) zu historisch passenden Rock-/Metal-Songs.

Ziel ist eine Trefferliste: **Folge ↔ Song ↔ Begründung ↔ Spotify/YouTube-Link** — nur bei engen Bezügen (Person, Schlacht, Ereignis, Ort oder konkrete Sage/Figur im historischen Kontext), keine losen Themen-Parallelen.

## Aktuelle Liste

- [HTML (sortierbar)](GAG_Metal_playlist.html) · <a href="https://sneumeister.github.io/GAG_Metal_Playlist/" target="_blank" rel="noopener noreferrer">Live-Ansicht (GitHub Pages)</a>

Die Live-Ansicht läuft über GitHub Pages und rendert die HTML-Datei im Browser. Solange das Repo privat ist, ist die URL ggf. noch nicht erreichbar; nach Umstellen auf **public** und Aktivieren von Pages (Settings → Pages → Source: **GitHub Actions**) funktioniert der Link.
